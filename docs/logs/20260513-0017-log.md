## Trait seams introduced or formalized

- **`FocusBackend`** (new, in `backends/mod.rs`) — backend dispatch. Five impls: `GnomeBackend`, `KdeBackend`, `WaylandBackend`, `X11Backend`, `LinuxConsoleBackend`. Boxed-future return type (`Pin<Box<dyn Future<...> + Send + 'static>>`) per PR-00 finding — RPIT-in-traits is not dyn-compatible on rustc 1.92.0. Supervisor's `start_backend` dispatches via `Box<dyn FocusBackend>`.
- **`DconfBackend`** (existing, formalized in `sni/settings.rs`) — gsettings/dconf abstraction. One production impl (`ShellDconfBackend`) plus test stubs via `SniSettingsStore::with_backend`.
- **`SniControlOps`** (existing, formalized in `sni/control_ops.rs`) — SNI menu action dispatch. One impl on `SniControl` that pattern-matches Local vs Dbus.

`LifecycleProvider` and `KanataClient` deliberately remain non-traits per plan §4.
