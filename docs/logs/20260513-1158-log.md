## Plan deviations / discoveries

1. **`pub(super)` → `pub(crate)` for helpers** (M2-PR-01 onwards): the plan §4 prescribed `pub(super)` for shared helpers. The executor judged `pub(super)` insufficient for the helpers → common → tests re-export chain and used `pub(crate)`. Accepted: the whole `tests`/`integration_tests` module is `#[cfg(test)]`-gated, so `pub(crate)` has zero production surface impact.
2. **`sni_presentation.rs` test count**: plan §2 estimated 14 SNI tests; actual audit during M2-PR-02 showed 17. The plan undercounted.
3. **`dbus_session_tests.rs` test count**: plan §2 estimated 14 tests in the "Private DBus Session for Testing" section; actual count was 15 (the plan missed `test_dbus_paused_changed_signal`). Caught in M2-PR-06.
4. **`dbus_session_tests.rs` LOC**: plan §6 PR-5 estimated ~1450 LOC, just under the 1500 ceiling. Actual landed at 1631, requiring M2-PR-06 (which the plan marked optional but the ceiling breach made required).
5. **`linux_console.rs` placement** (M1 carryover, unrelated to M2 but worth noting in the audit): `run_linux_console_backend_task` body inlined into `LinuxConsoleBackend::run` in PR-12. Not a deviation, just a documented choice in the PR-12 log.
